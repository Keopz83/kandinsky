# Kandinsky

Web app for creating code UML diagrams.

- **Frontend:** thin React client with a left menu (New, Save, Export, Import) and a shape palette (rectangle, directed edge).
- **Backend:** owns and processes the diagrams; exposes a REST API that the UI and external clients (e.g. an MCP server) use to manipulate diagram objects.
- **Formats:** import and export as PlantUML or Mermaid.

See [REQUIREMENTS.md](REQUIREMENTS.md) for the full list of requirements.
